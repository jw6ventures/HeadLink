Kotlin Android app (platform APIs only; no AndroidX or Google libraries) around the Rust
engine in `../core`. How it is put together is in
[docs/architecture.md](../docs/architecture.md), and the topic pages in
[docs/](../docs/README.md) cover each feature. Build with `tools/android-build.sh`; see
[docs/development.md](../docs/development.md).
