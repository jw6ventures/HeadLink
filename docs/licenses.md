The APK declares no AndroidX, Google Play services, gearhead, or other library
dependency; see the dependency listing in [P0.2 results](p0-2-results.md). P1.1 added
no shipped dependency. The TLS and discovery work added the OpenSSL, `openssl`, and
`prost` rows above. Compile-time-only crates in Cargo.lock are not linked into
artifacts: proc macros `openssl-macros` 0.1.1 and `prost-derive` 0.14.4 with `syn`,
`quote`, `proc-macro2`, `unicode-ident`, `anyhow`, `itertools`, and `either`, and build
scripts' `cc`, `shlex`, `find-msvc-tools`, `pkg-config`, and `vcpkg` (all MIT and/or
Apache-2.0; `unicode-ident` also Unicode-3.0). No private keys, proprietary runtime
libraries, or reference implementation source files are included. P5.5 is the first
slice to add a runtime dependency at all: before it, `app/build.gradle.kts` declared
none. `vtm-http`, VTM's only networked module, is deliberately excluded, so the map
read path has no network code in it. The source identity
is generated on the phone and never packaged.
